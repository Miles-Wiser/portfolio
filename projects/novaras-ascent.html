Project Overview

Novara's Ascent is a 2D platformer developed in Python and Pygame. The player navigates challenging levels using movement options including jumping, wall jumping, and dashing.

Alongside the game, I developed a custom level editor for creating and managing levels without directly editing the game's source code. The editor supports tile placement, automatic tiling, decorative elements, enemies, hazards, and other level components, as well as saving and loading levels.

I built Novara's Ascent as a large-scale personal project to learn how the systems behind games work and to gain experience developing interactive software from the ground up. The project currently contains three playable levels and remains unfinished, with additional planned features still to be implemented.

Development

One of the more challenging systems to develop was the game's camera. The camera needed to move through the game world while keeping the underlying coordinates of tiles and entities unchanged. I implemented the camera so that world coordinates are transformed into screen coordinates during rendering, allowing the same objects to maintain consistent positions in the game world while appearing to move as the camera moves.
